# Расчетно-графическое задание (Вариант 1)
**Тема:** Анализ линейной электрической цепи постоянного тока

**Исходные данные:**
- Источники ЭДС: $U_{01} = 40 \text{ В}$, $U_{02} = 80 \text{ В}$, $U_{03} = 80 \text{ В}$
- Источник тока: $J = 8 \text{ А}$
- Сопротивления: $R_1 = 10 \text{ Ом}$, $R_2 = 20 \text{ Ом}$, $R_3 = 2 \text{ Ом}$, $R_4 = 4 \text{ Ом}$, $R_5 = 5 \text{ Ом}$

---

## 1. Предварительный анализ схемы

Схема содержит $n = 3$ узла и $m = 5$ ветвей.
**Обозначим узлы:**
- **Узел 1 (верхний):** точка соединения ветвей с $R_1, R_3, J, R_2$.
- **Узел 2 (левый нижний):** точка соединения ветвей с $R_1, R_3, R_5$.
- **Узел 3 (правый нижний):** точка соединения ветвей с $J, R_2, R_5$.

**Выберем положительные направления токов ветвей:**
- $I_1$: вверх, от узла 2 к узлу 1 (совпадает с направлением $U_{01}$).
- $I_2$: вниз, от узла 1 к узлу 3 (совпадает с направлением $U_{02}$).
- $I_3$: вниз-влево, от узла 1 к узлу 2 (совпадает с направлением $U_{03}$).
- $I_5$: слева направо, от узла 2 к узлу 3 через резистор $R_5$.
- Ток в ветви с источником тока известен: $I_J = J = 8 \text{ А}$, направлен от узла 1 к узлу 3.

---

## 2. Расчет методом законов Кирхгофа (МЗК)

Необходимо составить 4 уравнения (для нахождения $I_1, I_2, I_3, I_5$). 
- По I закону Кирхгофа (ЗТК): $n - 1 = 2$ уравнения.
- По II закону Кирхгофа (ЗНК): $m - (n - 1) - m_J = 5 - 2 - 1 = 2$ уравнения.

**Уравнения ЗТК (для узлов):**
- Для узла 1: 
  $$I_1 - I_2 - I_3 - J = 0 \implies I_1 - I_2 - I_3 = 8$$
- Для узла 2: 
  $$-I_1 + I_3 - I_5 = 0$$

**Уравнения ЗНК (для контуров, обход по часовой стрелке):**
- **Контур 1** (узлы 2 $\rightarrow$ 1 $\rightarrow$ 2 через $R_1$ и $R_3$):
  $$I_1 R_1 + I_3 R_3 = U_{01} + U_{03}$$
  $$10 I_1 + 2 I_3 = 120 \implies 5 I_1 + I_3 = 60$$
- **Контур 2** (внешний: узлы 2 $\rightarrow$ 1 $\rightarrow$ 3 $\rightarrow$ 2 через $R_1, R_2, R_5$):
  $$I_1 R_1 + I_2 R_2 - I_5 R_5 = U_{01} + U_{02}$$
  $$10 I_1 + 20 I_2 - 5 I_5 = 120$$

**Решение системы:**
Из уравнений узлов выразим $I_3$ и $I_5$:
1) $I_3 = 60 - 5 I_1$
2) Из узла 1: $I_2 = I_1 - I_3 - 8 = I_1 - (60 - 5 I_1) - 8 = 6 I_1 - 68$
3) Из узла 2: $I_5 = I_3 - I_1 = (60 - 5 I_1) - I_1 = 60 - 6 I_1$

Подставим $I_2$ и $I_5$ во второе контурное уравнение:
$$10 I_1 + 20(6 I_1 - 68) - 5(60 - 6 I_1) = 120$$
$$10 I_1 + 120 I_1 - 1360 - 300 + 30 I_1 = 120$$
$$160 I_1 = 1780 \implies I_1 = \frac{178}{16} = 11.125 \text{ А}$$

Находим остальные токи:
- $I_2 = 6(11.125) - 68 = -1.25 \text{ А}$
- $I_3 = 60 - 5(11.125) = 4.375 \text{ А}$
- $I_5 = 60 - 6(11.125) = -6.75 \text{ А}$

---

## 3. Расчет методом контурных токов (МКТ)

Выберем 3 контура (обход по часовой стрелке):
- **Контур 11 (левый):** ветви с $R_1, R_3$. Ток $I_{11}$.
- **Контур 22 (правый):** ветви с $R_2, R_5, R_3$. Ток $I_{22}$.
- **Контур 33 (фиктивный для J):** проходит через источник $J$ (1 $\rightarrow$ 3) и замыкается через $R_2$ (3 $\rightarrow$ 1). Ток контура известен: $I_{33} = J = 8 \text{ А}$.

**Параметры контуров:**
- $R_{11} = R_1 + R_3 = 10 + 2 = 12 \text{ Ом}$
- $R_{22} = R_2 + R_5 + R_3 = 20 + 5 + 2 = 27 \text{ Ом}$
- $R_{12} = R_{21} = -R_3 = -2 \text{ Ом}$ (в $R_3$ токи $I_{11}$ и $I_{22}$ встречны)
- $R_{23} = -R_2 = -20 \text{ Ом}$ (в $R_2$ ток $I_{22}$ направлен вниз, а $I_{33}$ вверх)
- $E_{11} = U_{01} + U_{03} = 40 + 80 = 120 \text{ В}$
- $E_{22} = U_{02} - U_{03} = 80 - 80 = 0 \text{ В}$

**Система уравнений:**
$$12 I_{11} - 2 I_{22} = 120 \implies 6 I_{11} - I_{22} = 60$$
$$-2 I_{11} + 27 I_{22} - 20(8) = 0 \implies -2 I_{11} + 27 I_{22} = 160$$

**Решение:**
Из первого: $I_{22} = 6 I_{11} - 60$. Подставим во второе:
$$-2 I_{11} + 27(6 I_{11} - 60) = 160 \implies 160 I_{11} = 1780 \implies I_{11} = 11.125 \text{ А}$$
$$I_{22} = 6(11.125) - 60 = 6.75 \text{ А}$$

**Находим токи ветвей:**
- $I_1 = I_{11} = 11.125 \text{ А}$
- $I_2 = I_{22} - I_{33} = 6.75 - 8 = -1.25 \text{ А}$
- $I_3 = I_{11} - I_{22} = 11.125 - 6.75 = 4.375 \text{ А}$
- $I_5 = -I_{22} = -6.75 \text{ А}$ (знак минус, так как контур $I_{22}$ идет справа налево, а $I_5$ выбран слева направо).

---

## 4. Расчет методом узловых потенциалов (МУП)

Примем потенциал узла 2 равным нулю: $\phi_2 = 0 \text{ В}$.
Составим уравнения для узлов 1 и 3.

**Проводимости ветвей:**
- $G_{11} = \frac{1}{R_1} + \frac{1}{R_3} + \frac{1}{R_2} = 0.1 + 0.5 + 0.05 = 0.65 \text{ См}$
- $G_{33} = \frac{1}{R_2} + \frac{1}{R_5} = 0.05 + 0.2 = 0.25 \text{ См}$
- $G_{13} = G_{31} = -\frac{1}{R_2} = -0.05 \text{ См}$

**Узловые токи:**
- $J_1 = \frac{U_{01}}{R_1} - \frac{U_{03}}{R_3} - \frac{U_{02}}{R_2} - J = \frac{40}{10} - \frac{80}{2} - \frac{80}{20} - 8 = 4 - 40 - 4 - 8 = -48 \text{ А}$
- $J_3 = \frac{U_{02}}{R_2} + J = \frac{80}{20} + 8 = 4 + 8 = 12 \text{ А}$

**Система уравнений:**
$$0.65 \phi_1 - 0.05 \phi_3 = -48$$
$$-0.05 \phi_1 + 0.25 \phi_3 = 12$$

Умножим второе уравнение на 13 и сложим с первым:
$$3.2 \phi_3 = 108 \implies \phi_3 = 33.75 \text{ В}$$
$$-0.05 \phi_1 + 0.25(33.75) = 12 \implies \phi_1 = -71.25 \text{ В}$$

**Токи ветвей по обобщенному закону Ома:**
- $I_1 = \frac{\phi_2 - \phi_1 + U_{01}}{R_1} = \frac{0 - (-71.25) + 40}{10} = 11.125 \text{ А}$
- $I_2 = \frac{\phi_1 - \phi_3 + U_{02}}{R_2} = \frac{-71.25 - 33.75 + 80}{20} = \frac{-25}{20} = -1.25 \text{ А}$
- $I_3 = \frac{\phi_1 - \phi_2 + U_{03}}{R_3} = \frac{-71.25 - 0 + 80}{2} = \frac{8.75}{2} = 4.375 \text{ А}$
- $I_5 = \frac{\phi_2 - \phi_3}{R_5} = \frac{0 - 33.75}{5} = -6.75 \text{ А}$

---

## 5. Баланс мощностей

Условие: $\sum P_{\text{ген}} = \sum P_{\text{потр}}$

**Мощность потребителей (резисторов):**
$$P_{\text{потр}} = I_1^2 R_1 + I_2^2 R_2 + I_3^2 R_3 + I_5^2 R_5 + J^2 R_4$$
$$P_{\text{потр}} = (11.125)^2 \cdot 10 + (-1.25)^2 \cdot 20 + (4.375)^2 \cdot 2 + (-6.75)^2 \cdot 5 + 8^2 \cdot 4$$
$$P_{\text{потр}} = 1237.66 + 31.25 + 38.28 + 227.81 + 256 = 1791 \text{ Вт}$$

**Мощность источников (генераторов):**
Мощность источников ЭДС (ток и ЭДС сонаправлены = $+$, встречны = $-$):
$$P_U = U_{01}I_1 + U_{02}I_2 + U_{03}I_3 = 40(11.125) + 80(-1.25) + 80(4.375) = 445 - 100 + 350 = 695 \text{ Вт}$$

Мощность источника тока $J$:
Определим падение напряжения на самом источнике тока $U_J$. Напряжение всей ветви (от узла 1 к 3): $\phi_1 - \phi_3 = -105 \text{ В}$.
Напряжение на резисторе $R_4$: $U_{R4} = J \cdot R_4 = 8 \cdot 4 = 32 \text{ В}$.
Падение напряжения на идеальном источнике $J$: $U_J = (\phi_1 - \phi_3) - U_{R4} = -105 - 32 = -137 \text{ В}$.
Поскольку падение напряжения отрицательно, значит, в направлении тока происходит *подъем* потенциала, источник работает в режиме генератора.
$$P_J = J \cdot (-U_J) = 8 \cdot 137 = 1096 \text{ Вт}$$

**Суммарная генерируемая мощность:**
$$P_{\text{ген}} = P_U + P_J = 695 + 1096 = 1791 \text{ Вт}$$

**Вывод:** $1791 \text{ Вт} = 1791 \text{ Вт}$. Баланс мощностей сошелся идеально, расчет токов во всех ветвях выполнен абсолютно верно.
