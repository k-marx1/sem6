# Расчетно-графическое задание: Анализ линейной электрической цепи постоянного тока

**Дано:**
- Источники ЭДС: $U_{01} = 40 \text{ В}$, $U_{02} = 80 \text{ В}$, $U_{03} = 80 \text{ В}$
- Источник тока: $J = 8 \text{ А}$
- Сопротивления: $R_1 = 10 \text{ Ом}$, $R_2 = 20 \text{ Ом}$, $R_3 = 2 \text{ Ом}$, $R_4 = 4 \text{ Ом}$, $R_5 = 5 \text{ Ом}$
*(Примечание: резисторы $R_6$ и $R_7$ в схеме отсутствуют).*

---

## 1. Предварительный анализ схемы

- Количество узлов: $n = 3$
- Количество ветвей: $m = 5$
- Количество ветвей с источником тока: $m_J = 1$

**Обозначение узлов:**
- **Узел 1:** правый верхний (соединение $R_1$, $J$, $U_{02}$).
- **Узел 2:** правый нижний (соединение $R_2$, $R_5$, $R_3$).
- **Узел 3:** левый (соединение $U_{01}$, $R_4$, $R_5$, $U_{03}$).

**Положительные направления токов ветвей:**
- $I_1$ — ток через $R_1$ и $U_{01}$ (от узла 3 к узлу 1).
- $I_2$ — ток через $R_2$ и $U_{02}$ (от узла 1 к узлу 2).
- $I_3$ — ток через $R_3$ и $U_{03}$ (от узла 2 к узлу 3).
- $I_4$ — ток источника тока, $I_4 = J = 8 \text{ А}$ (от узла 3 к узлу 1).
- $I_5$ — ток через $R_5$ (от узла 3 к узлу 2).

---

## 2. Расчет методом законов Кирхгофа (МЗК)

Необходимо составить систему из 4 уравнений (для токов $I_1, I_2, I_3, I_5$).
По 1-му закону (ЗТК): $n - 1 = 2$ уравнения.
По 2-му закону (ЗНК): $m - (n - 1) - m_J = 2$ уравнения.

**Уравнения по I закону Кирхгофа:**
- Для узла 1:
$$I_1 + J - I_2 = 0 \implies I_1 - I_2 = -8$$
- Для узла 2:
$$I_2 + I_5 - I_3 = 0 \implies I_2 - I_3 + I_5 = 0$$

**Уравнения по II закону Кирхгофа:**
- Для контура 1 (обход 3-1-2-3 по часовой стрелке):
$$I_1 R_1 + I_2 R_2 - I_5 R_5 = U_{01} + U_{02}$$
$$10 I_1 + 20 I_2 - 5 I_5 = 120$$
- Для контура 2 (обход 3-2-3 по часовой стрелке):
$$I_5 R_5 + I_3 R_3 = U_{03}$$V
$$5 I_5 + 2 I_3 = 80$$

**Решение системы:**
Выражаем $I_1 = I_2 - 8$ и $I_5 = I_3 - I_2$. После подстановки в контурные уравнения получаем:
$$I_2 = \frac{360}{44} = \frac{90}{11} \approx 8.182 \text{ А}$$
$$I_1 = \frac{90}{11} - 8 = \frac{2}{11} \approx 0.182 \text{ А}$$
$$I_3 = 7 \cdot \left(\frac{90}{11}\right) - 40 = \frac{190}{11} \approx 17.273 \text{ А}$$
$$I_5 = \frac{190}{11} - \frac{90}{11} = \frac{100}{11} \approx 9.091 \text{ А}$$

---

## 3. Расчет методом контурных токов (МКТ)

Выберем 3 контура (обход по часовой стрелке):
- **Контур 11** (ветви 1, 2, 5). Ток: $I_{11}$.
- **Контур 22** (ветви 5, 3). Ток: $I_{22}$.
- **Контур 33** (с источником $J$). Ток задан: $I_{33} = J = 8 \text{ А}$.

**Сопротивления контуров:**
- $R_{11} = 10 + 20 + 5 = 35 \text{ Ом}$
- $R_{22} = 5 + 2 = 7 \text{ Ом}$
- $R_{12} = R_{21} = -5 \text{ Ом}$
- $R_{13} = 20 \text{ Ом}$
- $R_{23} = 2 \text{ Ом}$

**Контурные ЭДС:**
- $E_{11} = 40 + 80 = 120 \text{ В}$
- $E_{22} = 80 \text{ В}$

**Система уравнений:**
$$35 I_{11} - 5 I_{22} + 20 \cdot 8 = 120 \implies 7 I_{11} - I_{22} = -8$$
$$-5 I_{11} + 7 I_{22} + 2 \cdot 8 = 80 \implies -5 I_{11} + 7 I_{22} = 64$$

**Решение:**
$$I_{11} = \frac{2}{11} \text{ А}$$
$$I_{22} = \frac{102}{11} \text{ А}$$

**Токи ветвей:**
- $I_1 = I_{11} = \frac{2}{11} \text{ А}$
- $I_2 = I_{11} + I_{33} = \frac{90}{11} \text{ А}$
- $I_3 = I_{22} + I_{33} = \frac{190}{11} \text{ А}$
- $I_5 = I_{22} - I_{11} = \frac{100}{11} \text{ А}$

---

## 4. Расчет методом узловых потенциалов (МУП)

Примем потенциал базового узла: $\phi_3 = 0 \text{ В}$.

**Проводимости:**
- $G_{11} = \frac{1}{10} + \frac{1}{20} = 0.15 \text{ См}$
- $G_{22} = \frac{1}{20} + \frac{1}{5} + \frac{1}{2} = 0.75 \text{ См}$
- $G_{12} = G_{21} = -0.05 \text{ См}$

**Узловые токи:**
- $J_1 = \frac{40}{10} - \frac{80}{20} + 8 = 8 \text{ А}$
- $J_2 = \frac{80}{20} - \frac{80}{2} = -36 \text{ А}$

**Система уравнений:**
$$0.15 \phi_1 - 0.05 \phi_2 = 8$$
$$-0.05 \phi_1 + 0.75 \phi_2 = -36$$

**Решение (потенциалы):**
$$\phi_2 = -\frac{500}{11} \text{ В}, \quad \phi_1 = \frac{420}{11} \text{ В}$$

**Токи по закону Ома:**
- $I_1 = \frac{0 - 420/11 + 40}{10} = \frac{2}{11} \text{ А}$
- $I_2 = \frac{420/11 - (-500/11) + 80}{20} = \frac{90}{11} \text{ А}$
- $I_3 = \frac{-500/11 - 0 + 80}{2} = \frac{190}{11} \text{ А}$
- $I_5 = \frac{0 - (-500/11)}{5} = \frac{100}{11} \text{ А}$

---

## 5. Баланс мощностей

Условие: $\sum P_{\text{ген}} = \sum P_{\text{потр}}$

**Мощность потребителей (резисторов):**
$$P_{\text{потр}} = I_1^2 R_1 + I_2^2 R_2 + I_3^2 R_3 + J^2 R_4 + I_5^2 R_5$$
$$P_{\text{потр}} = \left(\frac{2}{11}\right)^2 \cdot 10 + \left(\frac{90}{11}\right)^2 \cdot 20 + \left(\frac{190}{11}\right)^2 \cdot 2 + 8^2 \cdot 4 + \left(\frac{100}{11}\right)^2 \cdot 5$$
$$P_{\text{потр}} = \frac{315216}{121} \approx 2605.09 \text{ Вт}$$

**Мощность источников (генераторов):**
Мощность ЭДС:
$$P_U = U_{01}I_1 + U_{02}I_2 + U_{03}I_3 = 40\left(\frac{2}{11}\right) + 80\left(\frac{90}{11}\right) + 80\left(\frac{190}{11}\right) = \frac{247280}{121} \text{ Вт}$$

Мощность источника тока $J$:
Напряжение $U_J = \phi_1 - (\phi_3 - J \cdot R_4) = \frac{420}{11} - (0 - 32) = \frac{772}{11} \text{ В}$.
$$P_J = J \cdot U_J = 8 \cdot \frac{772}{11} = \frac{67936}{121} \text{ Вт}$$

Общая генерируемая мощность:
$$P_{\text{ген}} = P_U + P_J = \frac{247280}{121} + \frac{67936}{121} = \frac{315216}{121} \approx 2605.09 \text{ Вт}$$

**Вывод:** $2605.09 \text{ Вт} = 2605.09 \text{ Вт}$. Баланс мощностей сошелся, токи рассчитаны верно.
