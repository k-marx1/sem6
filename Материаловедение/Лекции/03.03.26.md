**Легированные стали** 
Конструкционные стали. Буквы - кириллица. Цифра-процент целый. 

Менее 2.5% - низколегированные, до 10% - среднелегированные, более 10% - высоколегированные стали. 

**Жаропрочность** - никель. 

А - в конце марки - высококачественная сталь. 

Ш - шарикоподшипниковые стали. 

Серые чугуны - с графитом. 

Белые - углерод в виде карбидов. Хрупкий 

**Формы графитных включений**: 
1) графит вермикулярный
2) хлопьевидная 
3) шаровидная 
4) пластинчатая 

**Термическая обработка** - совокупность операций нагрева, выдержки охлаждения в различных средах, с целью изменения внутреннего строения сплава и получения требуемых свойств. Выдержка зависит только от размера и свойства самого материала (теплопроводности). 

**Терм обработка:**

| Предварительная                                                                       | Промежуточная                                                                                                                                         | Окончательная                        |
| ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| для подготовки структуры и свойств материала для последующих технологических операций | в процессе холодной пластической деформации материала для восстановления исходных пластических преимуществ. Для алюминиевых сплавов в прокатке полос. формирует свойство готового изделия а  |


| Термическая        | Химико-термическая                                                                                        | Термомеханическая      |
| ------------------ | --------------------------------------------------------------------------------------------------------- | ---------------------- |
| Только температура | Нагрев сплава в соответсвующих химических реагентах для изменения состава и структуры поверхностных слоев | Температура + нагрузка |

**Отжиг** - прогрев по сечению, отклонение подогрева. Меделнное охлаждение:
- для получения равновесной структуры 
- уменьшения хрупкости, увеличения вязкости 
- 30...100 град./час скорость охлаждения 
- подготовка структуры к последующей обработке 
- железо+цементит 

**Нормализация** - для высокоулеродистых сталей. Охлаждение на **воздухе**, не в печке, чуть медленнее.  
- феррит цементит 

**Закалка** - высокая скорость охлаждение. Резкое охлаждение. Металл в напряженном состоянии. 
Для снятия его - отпуск - догрев ниже критических точек. 
- нагрев стали до аустенического состояния, выдержка для завершения всех превращений и последующее ускоренное охлаждение. 
- углеродистые стали небольшого сечения - опускают в воду, остальное - в минеральные масла 

При быстрой закалке не успевает произойти превращение аустенита в перлит с выделением избыточного феррита или цементита (как по диаграмме состояния).
